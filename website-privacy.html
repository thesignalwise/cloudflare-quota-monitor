Privacy

Privacy Policy

Last updated: June 23, 2026. This policy describes how Cloudflare Quota Monitor handles account profiles, credentials, telemetry, and website data.

1. Data handled by the extension

The extension may process the Cloudflare API tokens, account IDs, and local account profile labels you enter, quota usage counts, limits, percentages, timestamps, and locally stored history samples returned by Cloudflare APIs.

2. Local storage

Account profiles, settings, and cached quota results are stored in chrome.storage.local on your browser profile. Configuration export creates a local JSON file selected by you. That file may include account profiles, API tokens, account IDs, latest quota cache, and dashboard history.

3. API transfer

The extension sends your Cloudflare API tokens only to https://api.cloudflare.com/ to verify access and read quota telemetry for configured accounts. TheSignalWise does not operate a backend service that receives your tokens or quota telemetry for this tool.

4. Website data

The public website is designed as a static site. It does not require an account and does not intentionally collect personal information through forms. Standard hosting logs may be processed by the hosting provider for security and operations.

5. Limited use

Cloudflare Quota Monitor uses Cloudflare API data only to provide quota monitoring, token validation, local cache history, and user-initiated configuration import/export. It does not use API data for advertising, profiling, resale, or unrelated analytics.

6. User control

  • You can remove stored extension data by clearing extension storage or uninstalling the extension.
  • You can revoke Cloudflare API tokens from your Cloudflare account dashboard.
  • You are responsible for protecting any exported JSON configuration file.

7. Changes

We may update this policy when the product, website, or legal requirements change. The updated version will be posted on this page with a new effective date.

8. Contact

For privacy questions, contact cloudflare-quota-monitor@thesignalwise.com.
