Built for people who run small Cloudflare stacks.

Quota Monitor is intentionally narrow: it reads usage signals, caches them locally, and makes limits easier to scan before a project surprises you.

Pressure-first dashboard

Sort counters by usage percentage, risk state, and recency so noisy low-risk metrics stay out of the way.

Local-first credentials

Your Cloudflare API token is stored in Chrome local storage and sent only to Cloudflare APIs.

Portable config

Import and export a local JSON configuration when you want to move setup between browser profiles.

Scheduled checks

Use Chrome alarms to refresh telemetry on a daily cadence without a hosted worker or account backend.

Create the right Cloudflare API token in a few minutes.

Cloudflare calls this an API Token. Use a scoped Custom token, not the legacy Global API Key, so the extension only receives read access to the account you choose.

1

Open API Tokens

In the Cloudflare dashboard, open My Profile → API Tokens, select Create Token, then choose Get started under Custom token.

Open Cloudflare tokens
2

Add read permissions

Name it Quota Monitor Read Only. Add Account → Account Analytics → Read first, then add read permissions for the Cloudflare products you want to monitor.

3

Scope and copy

Set Account Resources to the account you want to monitor. Continue to summary, create the token, copy it once, then paste it into the extension with your Account ID.

Recommended permissions

Start with the required permissions, then add optional product reads only for services you use.

Privacy posture

No hosted account. No quota telemetry resale. No broad browsing permissions.

Read privacy policy

Read-only Cloudflare access

The extension is designed for API tokens scoped to account analytics and read permissions for the Cloudflare products you want to monitor.

Browser-local cache

Settings, latest telemetry, and history samples stay in Chrome local storage unless you intentionally export a JSON file.

Transparent data path

Quota Monitor talks to Cloudflare APIs from your browser. SignalWise does not operate a backend service for this tool.
