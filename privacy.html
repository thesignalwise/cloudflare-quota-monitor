Privacy Policy

How this extension handles credentials, usage data, and local configuration files.

Local first v0.4.0

Data handled

Read-only
Cloudflare credentials

API tokens, account IDs, and local account profile labels entered by the user.

Quota telemetry

Usage counts, limits, percentages, timestamps, and local history samples returned by Cloudflare APIs.

Exported configuration file

Account profiles, API tokens, account IDs, latest quota cache, and dashboard history if the user chooses to export a local JSON configuration file.

Storage and transfer

Chrome storage

The extension stores account profiles, settings, and cached quota results in `chrome.storage.local` on the user's browser profile. It sends Cloudflare API tokens only to `https://api.cloudflare.com/` to verify token access and read quota telemetry for the configured accounts.

Configuration export creates a local JSON file selected by the user. It includes account profiles, settings, latest quota cache, and dashboard history. The extension does not upload backup data, operate a server, or receive, sell, or share user data.

Limited Use disclosure

Chrome policy

Cloudflare Quota Monitor's use and transfer of information received from Cloudflare APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide quota monitoring, API validation, local cache history, and user-initiated configuration import/export.

The extension does not use Cloudflare API data for advertising, profiling, resale, or unrelated analytics.
