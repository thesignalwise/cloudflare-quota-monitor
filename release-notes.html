v0.3.8

Released 2026-06-07

Current
Internationalization audit

Filled missing Simplified Chinese, Traditional Chinese, Japanese, and Korean translations across settings pages, release notes, popup labels, page titles, and accessibility text.

Localized page titles

Runtime localization now covers browser tab titles in addition to visible page content and translatable attributes.

Translation coverage guard

Automated tests now scan extension HTML for localizable text and fail when supported locales are missing dictionary entries.

Released 2026-06-07

Settings navigation now starts with Dashboard, then API configuration, monitoring, sync schedule, import/export, release notes, privacy, and about.

Native language selector

Release package refresh

Prepared a new extension package with the updated navigation, language selector, and release notes.

v0.3.5

Released 2026-06-01

Previous
Scheduled sync observability

Background refresh now records startup, scheduled, manual, skipped, success, and failure events in local sync logs.

Expandable trend charts

Dashboard mini charts can be opened in a larger modal with latest, low, and high values for the selected metric.

Adaptive chart scaling

Trend charts now use adaptive Y-axis scaling so low-usage metrics are no longer flattened by large quota limits.

Dashboard refresh progress

Manual dashboard refresh now shows staged progress while Cloudflare data is fetched, cached, and rendered.

Monitoring data portability

Configuration export now includes latest quota data, refresh timestamp, and dashboard history so imported profiles keep trend charts.

v0.3.4

Replaced online WebDAV backup with local JSON export and import to avoid broad host permissions and improve Chrome Web Store review readiness.

Removed optional all-site host permissions. The extension now only requests Cloudflare API access, storage, alarms, and notifications.

Translation cleanup

Filled missing release-note and privacy descriptions across Simplified Chinese, Traditional Chinese, Japanese, and Korean.
