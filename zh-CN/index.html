几分钟创建正确的 Cloudflare API Token。

Cloudflare 官方叫它 API Token。请创建有范围限制的 Custom token，不要使用旧的 Global API Key，这样扩展只会拿到你选择账号的只读权限。

1

打开 API Tokens

进入 Cloudflare 控制台的 My Profile → API Tokens，点击 Create Token，然后在 Custom token 区域选择 Get started。

打开 Cloudflare Tokens
2

添加只读权限

建议命名为 Quota Monitor Read Only。先添加 Account → Account Analytics → Read，再按需添加你要监控的 Cloudflare 产品读取权限。

3

限定账号并复制

将 Account Resources 限定到你要监控的账号。进入 summary 后创建 Token，复制只显示一次的密钥，再和 Account ID 一起填入扩展。

推荐权限

先添加必需权限，再只为你实际使用的产品添加可选读取权限。

必需Account Analytics: Read
Token / 账号检查User Details: Read · Memberships: Read
核心开发者产品Workers Scripts: Read · Workers KV Storage: Read · Workers R2 Storage: Read · D1: Read
可选覆盖Cloudflare Pages: Read · Queues: Read · Hyperdrive: Read · Workers AI: Read · Zero Trust: Read

Cloudflare 官方文档提供了 Custom token 创建、Account Analytics 只读权限和 Account ID 查找说明。
