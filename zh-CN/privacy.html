隐私政策

最后更新：2026 年 6 月 6 日。本政策说明 Cloudflare Quota Monitor 如何处理凭据、遥测和网站数据。

1. 扩展处理的数据

扩展可能处理你输入的 Cloudflare API Token 和账号 ID、Cloudflare API 返回的配额用量计数、限制、百分比、时间戳，以及本地保存的历史样本。

2. 本地存储

设置和缓存的配额结果会存储在浏览器配置文件的 chrome.storage.local 中。配置导出会创建一个由你选择保存位置的本地 JSON 文件。该文件可能包含 API Token、账号 ID、最新配额缓存和仪表盘历史。

3. API 传输

扩展只会把你的 Cloudflare API Token 发送到 https://api.cloudflare.com/，用于验证访问权限和读取配额遥测。TheSignalWise 不为这个工具运营接收 Token 或配额遥测的后端服务。

4. 网站数据

公开网站按静态站设计，不需要账号，也不会通过表单主动收集个人信息。托管提供商可能会为了安全和运维处理标准访问日志。

5. 有限使用

Cloudflare Quota Monitor 只会将 Cloudflare API 数据用于配额监控、Token 验证、本地缓存历史，以及用户主动发起的配置导入/导出。它不会将 API 数据用于广告、画像、转售或无关分析。

6. 用户控制

  • 你可以通过清除扩展存储或卸载扩展来移除已存储的数据。
  • 你可以在 Cloudflare 账号后台撤销 API Token。
  • 你负责保护任何导出的 JSON 配置文件。

7. 政策变更

当产品、网站或法律要求发生变化时，我们可能更新本政策。更新后的版本会发布在本页面，并标注新的生效日期。

8. 联系方式

如有隐私相关问题，请联系 cloudflare-quota-monitor@thesignalwise.com。
